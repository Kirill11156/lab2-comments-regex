# Лаба 2, вариант 29 - поиск комментариев в коде

Программа на Python: проверяет строку (комментарий или нет) и ищет
комментарии `#`, `//` и `/* */` в коде, введённом вручную или
загруженном из файла.

Запуск: `python main.py`
Тесты: `python -m unittest test.py`

- `main.py` - регулярки и сама программа
- `test.py` - тесты (unittest, 16 штук)
